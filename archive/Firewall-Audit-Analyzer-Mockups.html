Finding Detail

Audit Result › FW-001
CRITICALFW-001
Open

Any–Any–Any firewall policy terdeteksi

Kategori: Firewall Rulebase · Penalti skor: −25

Deskripsi

Policy ID 34 pada VDOM root mengizinkan lalu lintas dari any source ke any destination dengan service ALL, tanpa IPS/AV/Web Filter dan tanpa logging. Ini membuka permukaan serangan yang sangat luas dan menyulitkan deteksi anomali.

Evidence (config snippet)

edit 34
    set srcintf "any"
    set dstintf "any"
    set srcaddr "all"
    set dstaddr "all"
    set service "ALL"
    set action accept
    set logtraffic disable
next

Rekomendasi

  • Batasi source/destination ke subnet & host yang benar-benar diperlukan.
  • Ganti service ALL dengan service spesifik (port/protokol tertentu).
  • Aktifkan security profile (IPS, AV, Web Filter) dan set logtraffic all.
  • Tambahkan comment & owner pada policy untuk change management.
